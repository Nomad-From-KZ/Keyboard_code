# Windows Code Controller Layer

Специализированная прослойка между физической клавиатурой и онлайн-компиляторами в браузере.

## Особенности
- **Тайпинг-маскарад:** Физические клавиши служат триггерами последовательного ввода предзагруженного блока кода.
- **Маскировка (Visual Guidance):** Подсказка в интерфейсе `Next: {` отображает, какой именно символ будет отправлен в редактор следующими нажатиями.
- **Глобальные хоткеи выбора:** Выбор блока/варианта через `1`, `Shift+1`, `Ctrl+1` без их отправки в браузер.
- **Синхронизация Backspace:** Вводит Backspace в редактор и отматывает позицию блока на 1 символ назад.
- **Защита от зацикливания:** Игнорирование инжектированных через `SendInput` событий с флагом `LLKHF_INJECTED`.
