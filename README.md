# Keyboard_code
Keyboard Code Controller — утилита на Python/PyQt6 для эмуляции посимвольного ввода кода с клавиатуры по хоткеям.
• Загрузка блоков кода из файлов и редактор. 
• Кастомные хоткеи и задержка печати. 
• Отслеживание прогресса и подсказка следующего символа. 
• Поддержка Backspace, паузы (F8) и сброса (Ctrl+R).  
Запуск: через start.bat.
